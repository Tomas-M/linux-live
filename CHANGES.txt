Unreleased changes
==================

Linux Live Kit
--------------
- Preserve the initramfs diagnostic logs livedbg and from.log after switching
  to the live system, including text-mode boots.
- Allow individual files larger than 4 GiB in generated ISOs, including large
  SquashFS modules, using ISO 9660 level 3.
- Fix DHCP configuration for HTTP ISO boot with ip=dhcp and generate the DHCP
  script portably across supported shells.
- Support Zstandard-compressed kernel modules (*.ko.zst), remove their
  compressed copies after extraction and abort the build if extraction fails.
  Normalize modules.order entries for gzip, XZ and Zstandard compression.
- Detect XZ Utils without relying on English text in its help output.
- Include VirtIO block, SCSI, transport and auxiliary drivers and their
  dependencies in the initramfs. Complete partially copied module directories
  instead of skipping their remaining drivers.
- Document HTTP ISO boot with DHCP and the optional Zstandard build dependency.
- In the from=ask disk picker, exclude swap by filesystem type rather than by
  matching "swap" anywhere in a device label.

Slax
----
- Replace the separate BIOS boot partition on newly erased GPT disks with
  reserved BIOS embedding space before the first usable LBA. Preserve BIOS
  and UEFI boot without exposing a raw partition that Windows offers to format.
- Let the Linux installer detect and read its current optical boot medium
  directly, including virtual CD/DVD drives, without requiring another ISO
  file. Follow executable symlinks and bind mounts independently of the working
  directory. Support optical-device aliases and validate the Slax payload
  before advancing to target selection.
- Show a clear message when no suitable target disks are found. Hide it when
  a disk becomes available and restore it when the last disk is removed.
- Fix spacing above the Install and Cancel buttons in the Linux installer's
  confirmation dialog.
