Unreleased changes
==================

Linux Live Kit
--------------

- Show device search results, mount errors and storage messages when live data
  cannot be found, with a complete diagnostic report retained in RAM.
- Automatically size persistence containers from their backing filesystem and grow
  existing containers without shrinking them; remove the perchsize boot parameter.
- Update DynFileFS to 6.02 with incremental checkpoints and automatic format-500 conversion.
- Keep DynFileFS backing files and automatic filesystem freezing accessible after
  switching from the initramfs to the live root, fixing persistent boot I/O errors.
- Restore a saved state at profile startup using its stable ID; keep the
  request on failure and stop for recovery instead of silently continuing in RAM.
- Simplify boot profile menus to selection and clean-profile creation; remove
  copying, renaming and name entry. Refresh the disk list with F5 after connecting a drive.
- Preserve the starting state before persistent writes and apply save/discard
  policy at the next activation; protect scheduled restore points during recovery.
  Recover interrupted creation of the starting state without losing unrelated points.

Slax
----

- Prefer the installed variants of Slax's held packages in APT, preventing rebuilt
  packages from appearing as same-version updates while retaining ordinary updates.
- Increased default storage size for persistent changes. Previously, the default
  virtual size was 16 GB; it now follows the actual capacity of the filesystem
  storing the profile without unnecessary overhead.
- Call persistent environments Slax profiles and saved states restore points.
  Choose a profile or restore point during startup; keep ordinary resume automatic.
- Add Slax Status to the desktop tray, with anchored storage warnings, estimated
  available space, Save this run and native profile/restore-point management.
  Browse saved files read-only and choose the next profile or restore point.
- Include whiptail for debconf's text dialogs during package installation,
  avoiding frontend initialization warnings.
- Highlight the Start button on hover using the shared GTK panel style.
- Use the same desktop defaults for root, guest and new accounts, including the
  panel, shortcuts, appearance and user-specific startup after a text-mode login.
- Support the firmware framebuffer when starting the desktop after a nomodeset
  boot, and fix a Fluxbox crash when monitor information becomes unavailable.
- Allow the active local guest session to restart or shut down through logind.
- Replace shared-folder bind mounts with ACLs and XDG directories, keeping root
  and guest downloads separate, including their sandboxed application profiles.
- Keep the Linux installer UPX-compressed on installation media and unpacked in
  the running desktop.
