Unreleased changes
==================

Linux Live Kit
--------------

- Increase the generated fstab device timeout from 10 to 30 seconds.
- Link every available BusyBox applet in initramfs, including strings, using
  the complete applet list instead of parsing formatted help output.
- Include common vendor HID keyboard drivers and Apple SPI keyboards with their
  controllers in initramfs so they are available for early boot menus.
- Skip EFI System Partitions during live-data discovery, storage selection and automount.
- Update the static initramfs blkid and eject to util-linux 2.42.4 and Mini Commander to 2.0.
- Show device search results, mount errors and storage messages when live data
  cannot be found, with a complete diagnostic report retained in RAM.
- Automatically size persistence containers from their backing filesystem and grow
  existing containers without shrinking them; remove the perchsize boot parameter.
- Update DynFileFS to 6.03 with incremental checkpoints and automatic format-500 conversion.
- Safely publish DynFileFS metadata and saving-policy updates, and wait for persistent
  storage and its backing filesystem to finish closing before powering off.
- Report reusable capacity released by deleting individual DynFileFS saved states,
  using cached block ownership instead of scanning saved filesystem contents.
- Allow disabling DynFileFS automatic end-of-run points without disabling explicit
  saved states or normal filesystem synchronization.
- Rename DynFileFS saved states by stable identity while retaining their data,
  ancestry, open read-only views and restore targets. Expose saved images by ID.
- Keep DynFileFS backing files and automatic filesystem freezing accessible after
  switching from the initramfs to the live root, fixing persistent boot I/O errors.
- Restore a saved state at storage startup using its stable ID; keep the
  request on failure and stop for recovery instead of silently continuing in RAM.
- Keep one DynFileFS changes.dat directly in changes on every filesystem,
  including native Linux storage; ignore older numbered profile directories.
- Choose a drive and then a saved state during boot. Fresh start restores
  Initial state while retaining history; F5 refreshes the drive list.
- Preserve the starting state before persistent writes and apply save/discard
  policy at the next activation; protect restore targets during recovery.
  Recover interrupted creation of the starting state without losing unrelated points.
- Give new containers a permanent Initial state saved state after
  formatting and filesystem growth; hide the unusable pre-formatting point.

Slax
----

- Sharpen the Slax Status application icon and bring its drive symbols closer together.
- Keep Slax Status saving and restore choices consistent with boot recovery after
  an interrupted policy update.
- Add a RAM guide to Slax Status with mounted-drive setup and restart, preserving
  existing saved changes and explaining that the current RAM run is discarded.
  Match the saved-state manager's plain split layout while keeping the loss warning highlighted.
  Setup and confirmed restores select the drive for automatic resume using the
  same durable marker as boot, with timestamps newer than mounted selections.
  Show a RAM chip beside RAM source and changes locations in the tray and manager.
  Simplify the RAM guide's text hierarchy, align its columns and keep drive icons
  on actual drive choices. Place Refresh beside the mounted-drive heading.
  Give both columns more space around the center divider.
  Retain comfortable outer padding when the guide stacks in a narrow window.
  Scope saving and saved states explicitly to future runs, including the restart
  confirmation, and explain that the current RAM run cannot be transferred.
- Prepare the status bubble's current size before opening it, avoiding a narrow
  first frame and a later width or height jump.
- Reject malformed status-service replies while retaining confirmed saved-state
  history. Traverse long histories without recursion and avoid timestamp-sort overflow.
- Automatically restart a failed Picom compositor while the desktop is running,
  sharing the panel's supervision and retaining failure diagnostics.
- Include Debian's signed network GRUB for UEFI PXE boot, reusing the existing
  shim and MokManager. Compress network loaders until pxe starts and serve the
  paths expected by shim and GRUB alongside the existing BIOS network bootstrap.
- Restore saved states through a confirmed immediate restart, with a Save this run
  choice, automatic file-view cleanup and storage synchronization before restarting.
- Remove obsolete next-start scheduling, blue target markers and cancellation controls.
  Keep only the confirmed restart's internal boot handoff and failure cleanup.
- Keep saved-state sizes visible during file browsing and prevent duplicate file views.
  Rename states in place without flashing controls; remove the separate restart button.
- Clarify that saved states keep installed programs, settings and saved files,
  not open windows or unsaved work. Use a smaller Save this run switch throughout
  Slax Status, including restore confirmations.
- Shorten saved-state action labels, move Open files last and separate sizes and dates with a middle dot.
- Skip bookmark updates without a valid home or when settings resolve to filesystem-root paths.
- Keep the Don't save explanation fully readable in the side panel.
- Move Show removed states and Go to now into the shared bottom bar. Align the checkbox
  and align Go to now with the tree's right edge, with an upward arrow, padding,
  pointer and click feedback.
- Remove the unused SystrayIconLauncher utility from the desktop module.
- Include Slax Status and Keyboard layout in the predefined tray icon order.
- Use Saved states throughout the desktop, boot menu and installers, with
  Save current state, Rename saved state and Delete saved state actions.
- Clarify boot-menu labels for resuming saved changes and running from RAM without automount.
- Fit the status bubble's width to its current content, with a 350 px minimum
  and no wrapping of its rows.
- Automatically disconnect saved-state file views after their File Manager
  windows close, including across tray or broker restarts; remove Close files.
- Keep saved-state controls visually stable when switching applications.
- Remove the repeated deletion-space explanation from saved-state details.
- Right-align available space in the status bubble and separate its heading, drive details and capacity.
- Keep save switches and saved-state actions from flashing during policy writes;
  serialize rapid save changes and apply the latest choice without interrupting animation.
- Refresh saved-state details without replacing controls or dimming their text.
  Remove the pressed inset from history rows.
- Use ordinary left-aligned text in standard GTK 3 message dialogs.
- Keep switch tracks blue to the left of the moving thumb and gray to its right,
  avoiding the color flash at the end of animation or dragging.
- Clarify saved-state dialogs and give them normal window titles. Move
  Show removed states below history.
- Give green action buttons in Slax Status and Partition Manager the same
  raised appearance and pressed feedback as ordinary buttons.
- Release the shutdown splash console before systemd's initramfs handoff,
  preventing restarts from hanging until a key is pressed.
- Rename saved states without changing their contents,
  including international names and spaces. Wrap inspector titles, omit redundant
  parent information and button tooltips, and reduce confirmation text margins.
- Make Don't save suppress automatically saved states for the discarded run,
  including when restoring a different saved state.
- Show space reusable after deleting a saved state and remove repeated-name
  tree tooltips. Refresh size figures without rebuilding unchanged history rows.
- Keep the Save this run switch from getting stuck between positions during
  repeated clicks or dragging while storage status refreshes.
- Keep SSH socket activation disabled by default, avoiding unnecessary VSOCK
  discovery errors on virtual machines without a VSOCK transport.
- Keep a consistent gap between buttons in standard GTK message dialogs.
- Replace profile management with saved states for the currently used drive.
  Choose storage only at boot; explain persistence and recovery with an example
  when running in RAM. Keep confirmation left and Cancel right.
- Open saved-state files at the saved filesystem root instead of the user's home.
- Fix Slax Status crashes when clicking informational rows in empty or loading history views.
- Show a clean Initial state for new storage; reserve Current state for the
  running store. Preserve the state being left before a restore when saving is
  enabled, and always retain existing history.
- Increase the gap between Partition Manager's operation percentage and progress bar.
- Keep the saved-state window open when toggling its tray bubble, remove storage Details,
  and fix asynchronous save switches, footer movement and bubble positioning.
- Exclude EFI System Partitions from automatic mounting and storage discovery;
  prevent both installers from using them for Slax data while retaining EFI-on-data fallback.
- Keep desktop shortcuts available in tray bubbles and refine Slax Status spacing
  and saved-state actions. Show used space in the bar while keeping available space in text.
- Use light file icons for Windows shortcuts, applications, libraries and images.
- Prefer the installed variants of Slax's held packages in APT, preventing rebuilt
  packages from appearing as same-version updates while retaining ordinary updates.
- Increased default storage size for persistent changes. Previously, the default
  virtual size was 16 GB; it now follows the actual capacity of the filesystem
  storing saved changes without unnecessary overhead.
- Add Slax Status to the desktop tray, with anchored warnings, estimated available
  space, Save this run and native saved-state management. Browse saved files
  read-only and restore saved states through a confirmed restart.
- Include whiptail for debconf's text dialogs during package installation,
  avoiding frontend initialization warnings.
- Highlight the Start button on hover using the shared GTK panel style.
- Use the same desktop defaults for root, guest and new accounts, including the
  panel, shortcuts, appearance and user-specific startup after a text-mode login.
- Support the firmware framebuffer when starting the desktop after a nomodeset
  boot, and fix a Fluxbox crash when monitor information becomes unavailable.
- Allow the active local guest session to restart or shut down through logind.
- Replace shared-folder bind mounts with ACLs and XDG directories, keeping root
  and guest downloads separate, including their sandboxed application profiles.
- Keep the Linux installer UPX-compressed on installation media and unpacked in
  the running desktop.
