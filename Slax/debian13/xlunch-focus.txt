Slax xlunch Focus integration

The footer is aligned to the grid with bottom_margin=0, moving its help 28 px
down and giving the icons 28 px more height without covering the close button.
The grid uses fade_height=64 to fade clipped icons, labels and highlights into
the wallpaper at both edges. Fades shrink away at the beginning and end of the list.

The Slax profile is modules/03-desktop/rootcopy/etc/xlunch/focus.ini.
grid.uninstalled_icon_transparency=50 dims icons with unavailable installer
targets, and grid.installed_first=true puts available apps first. Both groups
keep their original order. Hover restores the full icon without moving it.
Labels and help text remain unchanged. Optional desktop entries declare their
actual executable with X-Xlunch-Executable; availability is checked from that
command even when the catalog was loaded from cache.
groups.order follows the alphabetical order of displayed category labels.
Session uses view=grid and exactly the same 64 px icons, columns, cell dimensions
and hover as application categories. Slax's original action images are scaled
by the shared renderer. It replaces applications in the main viewport. All labels, icon
paths, action order and commands are configuration; xlunch has no Slax actions.

The header uses Slax's original clover icon and white DejaVu Sans Bold Slax text. The icon is
rootcopy/usr/share/icons/hicolor/128x128/apps/slax.png, copied unchanged from
https://www.slax.org/images/clover-round.png. header.caption is empty and
heading.show_count=false hides application and Session counts above the grid.
The Session divider matches the Favorites divider with no extra margin.
Sidebar and Session hover use a transparent fill and the same white outline as
keyboard focus. Only the selected navigation item receives the translucent fill.

The three configured commands play Slax's existing shutdown sound and then
log out with killall Xorg, restart with reboot, or shut down with poweroff.
fblogout and logout.dsv remain available for Fluxbox's Exit / Logout entry.
fbappselect directly starts xlunch with this profile. Desktop entries launch
through fbstartupnotify and gio, using the same busy cursor as Fluxbox.
fbinstall starts the notifier again when launching the installed application.
The notifier restores the cursor after a window appears or after 30 seconds.
Slax desktop overrides live in each module's rootcopy/usr/local/share/applications
using the package's original desktop filename. XDG gives them precedence over
the retained /usr/share/applications files, so APT upgrades do not create a second
icon or replace Slax's fbliveapp command. Favorites and MIME defaults use these
canonical IDs, including debian-xterm.desktop and SciTE.desktop.
Global search also includes applications while Session is open. With an empty
command_prefix, Enter recognizes an installed executable as the first word and
prefers an application with that executable. Otherwise fbcommand runs GUI
commands directly and console commands in xterm, retaining output until a key
is pressed; interactive ncurses programs close normally when they finish.

03-desktop/build includes libglib2.0-bin for gio. 03-desktop/compile packages the
generic xlunch interface icons and logo and validates the Slax INI with the
compiled binary before packaging. These files belong to the xlunch release,
not to a copied local C patch inside Slax.

03-desktop/compile downloads the published xlunch v5.4.0 release. The profile
validation prevents an incompatible executable from being packaged.

For an incremental rebuild, replace the executable and assets in 03-desktop,
apply the new rootcopy files, retain /usr/bin/fblogout and
/etc/xlunch/logout.dsv for Fluxbox, and include gio and its runtime
dependencies. Repack 03-desktop and the application-category changes in 04-apps,
then recreate the ISO. Follow the repository's normal incremental-build rules.
When applying the desktop relocation to an existing build, remove the old Slax
rootcopy entries from /usr/share/applications, restore package desktop originals
removed by the previous cleanup, and install the new /usr/local/share/applications
overrides. Include 05-chromium when restoring its package desktop entry. A fresh
build preserves the originals automatically.

05-chromium/copy runs xlunch --ui-config /etc/xlunch/focus.ini --rebuild-cache
after all applications and icons are present. Root and guest get separate
uncompressed snapshots in ~/.cache/xlunch, matching their runtime locale,
PATH and XDG environment. Rebuild this final-module cache after changing
desktop entries, icons or the Focus profile, then repack 05-chromium too.
xlunch opens the snapshot immediately, refreshes it at nice priority 19 after
the first frame and cancels refresh before launching an application.

Do not test real shutdown actions during automatic UI checks. Use xlunch's
--outputonly with harmless action fixtures to verify configurable icons, order,
search, keyboard/mouse input and output selection without executing commands.
