
 Welcome to Slax.

 Use the arrow keys to choose a boot option, [Enter] to boot, or [e] to
 manually edit the boot command line in order to customize how Slax boots.
 A detailed description of various boot parameters is provided below.

 * toram: If specified, all data are copied to memory during startup so you
   can eject the boot device. Needs enough RAM to store all necessary files.

 * nosound: If specified, sound devices are muted during startup

 * text: Start in the text console without the boot splash, Xorg or the desktop.
   The text-only menu entry shows warnings and errors; boot details remain in the journal.

 * nomodeset: Keep the firmware display mode without accelerated graphics.
   The text-only menu entry uses this to preserve a visible UEFI console.

 * perchdir=[resume|new|ask|device]: All changes you make to Slax can be
   saved to a writable media. By default, the directory /slax/changes is
   used for this purpose if you run Slax from flash drive or disk.

   perchdir=ask lists sessions from /slax/changes on all writable disks.
   Creating a new session asks which disk to use, including disks without
   sessions.

   perchdir=resume resumes the most recently used session across writable
   disks, comparing the modification time of each last_session.txt file.
   If no previous session is found, it uses the boot medium as before.
   To select a specific storage directory, use perchdir=/dev/writable_device/path

 * perchsize=[size_MB]: When stored on non-linux filesystem such as FAT32,
   sessions are limited to maximum size of 16GB. You can increase the limit
   with this parameter, use just once. For example perchsize=32GB

 * from=[file|path|device|ask] is used to set a directory or even device
   from which is Slax started. For example, from=/slax, from=/dev/sr1/data
   or from=http://some_url/to_iso_file.iso, or from=ask to select from list

 * bootuuid=[filesystem_UUID]: GRUB supplies this automatically to prefer
   data on the filesystem containing the kernel. An explicit from= overrides it.

 * noload=[regex] is used to specify what modules will not be loaded. Use
   a regular expression, for example noload=04-chromium or noload=firmware|chromium
